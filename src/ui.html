Built-in Cyber & Security SQL Functions (UDFs)

Use these custom functions in your SQL queries against any log format.

detect_threat(column) SecOps

Scans URL or string for exploit signatures: SQL Injection, XSS, Log4Shell/JNDI, Path Traversal (LFI), RCE, SSRF, and Scanners.

SELECT request_uri, detect_threat(request_uri) AS threat FROM logs
ip_in_cidr(ip, 'cidr/prefix') Network

Evaluates whether an IPv4 or IPv6 string falls within a specified CIDR block (e.g. 10.0.0.0/8, 192.168.0.0/16).

SELECT remote_addr, ip_in_cidr(remote_addr, '10.0.0.0/8') AS is_corp FROM logs
shannon_entropy(column) Anomaly

Calculates Shannon entropy score (0.0 to 8.0) of a string. High entropy flags base64 payloads, obfuscation, or DGA domains.

SELECT request_uri, shannon_entropy(request_uri) FROM logs WHERE shannon_entropy(request_uri) > 4.2
mask_pii(column) Privacy

Anonymizes PII like email addresses, replacing them with [REDACTED_EMAIL] for GDPR/HIPAA compliance.

SELECT mask_pii("user"), event FROM logs
cluster_template(column) Drain / NLP

Replaces dynamic variables (IPs, UUIDs, IDs, numbers) with <*> to aggregate millions of logs into common templates.

SELECT cluster_template(message), count(*) FROM logs GROUP BY 1 ORDER BY 2 DESC
url_decode(column) & parse_ua(column) Utility

Decodes percent-encoded URIs and extracts browser/crawler details from User-Agent headers.

SELECT url_decode(request_uri), parse_ua(http_user_agent) FROM logs
