2. Built-in Cyber Security & Log Parser SQL Functions (UDFs)

detect_threat(column) SecOps

Detects SQL Injection, XSS, Log4Shell/JNDI, Path Traversal (LFI), RCE, SSRF, and Scanners.

ip_in_cidr(ip, 'cidr/prefix') Network

Checks whether an IPv4 or IPv6 address belongs to a CIDR subnet (e.g. 10.0.0.0/8, 192.168.0.0/16).

shannon_entropy(column) Anomaly

Calculates Shannon information entropy (0.0–8.0) to spot obfuscated base64 or high-entropy payloads.

extract_token / extract_extension / to_timestamp / index_of LogParser 2.2

Classic Microsoft Log Parser functions for splitting strings, extracting extensions, and combining timestamps.

mask_pii(column) & cluster_template(column) Privacy & Drain

Redacts email addresses to [REDACTED_EMAIL] and clusters dynamic tokens (IPs, UUIDs, numbers) into <*>.

url_decode(col) & parse_ua(col) HTTP Utility

Percent-decodes URLs and classifies User-Agents into Bot/Scanner vs Browser/OS.
